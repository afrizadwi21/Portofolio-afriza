# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters, tech leads, engineering teams, and potential collaborators evaluating M. Afriza Dwi I for internships, junior web development roles, or collaborative software engineering opportunities.

## Product Purpose

A high-craft, editorial web portfolio showcasing the genuine skills, real projects, learning journey, and technical depth of a vocational high school software engineering student (SMK Negeri 4 Padalarang). It communicates curiosity, practical engineering ability, and a strong trajectory toward full-stack development without inflating achievements or relying on AI boilerplate aesthetics.

## Positioning

Honest, high-contrast, editorial craft: combines rigorous technical aesthetics (interactive particle field, terminal aesthetics, marquee tech stacks) with restrained typography and authentic student projects (DistribuCore SaaS, LaundryFlow Odoo backend).

## Operating Context

Desktop and mobile browsers, light and dark operating systems, recruitment screening workflows, GitHub profile cross-referencing.

## Capabilities and Constraints

- Next.js (App Router), TypeScript, Tailwind CSS, framer-motion, lucide-react, next-themes.
- Fully static preview / frontend-only; no backend database or auth required.
- Accessible color contrast in both dark and light modes.
- Strict adherence to prefers-reduced-motion.
- Fluid responsive layout (desktop-first editorial layout scaling down gracefully to mobile).

## Product Principles

1. **Truth Over Hype**: Represent real student/internship projects honestly without synthetic metrics or fake testimonials.
2. **High Tactile Craft**: Interactive canvas particle mesh, tactile keyboard controls for modals, buttery marquee ticker, responsive theme transition.
3. **Editorial Restraint**: Generous spacing, distinct typography (Space Grotesk + JetBrains Mono), intentional color hierarchy.
4. **Performance & Accessibility**: Respect user motion preferences, maintain crisp contrast ratios, and load fast.
